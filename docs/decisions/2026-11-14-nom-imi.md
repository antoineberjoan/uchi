# Nom imi partout dans le code

Date : 2026-11-14 · Statut : acceptée
Décidé par : Antoine

## Contexte

Le nom affiché était déjà imi. Les modules, l’identifiant et plusieurs textes gardaient un autre préfixe, reporté le 13 novembre comme trop large pour le lot de marque.

## Décision

Les modules s’appellent `ImiCore`, `ImiDesign`, `ImiUI`, `ImiPlatform`, `ImiMac`, `ImiIOS`, `ImiKeyboard`. Le paquet Swift s’appelle `Imi`. Le nom affiché, le paquet Mac et le clavier restent **imi**. L’identifiant est `local.imi.personnel`. L’App Group est `group.local.imi.personnel`. Le service du trousseau est `local.imi.personnel`. Les fichiers de l’ancienne palette sont retirés. Le dépôt GitHub reste `antoineberjoan/uchi`.

## Options

| Option | Effet |
| --- | --- |
| Garder l’ancien préfixe de compilation | Écartée : Antoine veut un seul nom |
| Renommer aussi le dépôt GitHub | Non fait ici : les réglages du dépôt ne sont pas accessibles à l’agent |
| Préfixe Imi, nom affiché imi | Retenue |

## Conséquences

Une installation déjà faite ne retrouve pas les clés : le groupe et le service du trousseau ont changé. Il faut ressaisir la clé dans Réglages. Les dossiers, `Package.swift`, le projet Xcode et les tests suivent les nouveaux noms.
