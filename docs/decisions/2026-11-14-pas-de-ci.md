# Pas de CI GitHub

Date : 2026-11-14 · Statut : acceptée
Décidé par : Antoine (le forfait GitHub est épuisé)

## Contexte

Le dépôt lançait des workflows hébergés : contrôles Sophos, recherche de secrets, construction macOS. Le forfait Actions est épuisé. Un job rouge à chaque envoi ne prouve plus rien.

## Décision

Retirer les workflows. La preuve est locale : `./controler.sh` là où Sophos est cloné, puis `swift test` et `bash Scripts/build-app.sh` sur un Mac. L’iPhone se vérifie depuis Xcode, sur l’appareil.

## Options

| Option | Effet |
| --- | --- |
| Laisser les workflows | Écartée : ils échouent ou consomment le forfait |
| Runner sur le Mac | Écartée : Antoine ne veut pas de CI |
| Retirer les workflows | Retenue |

## Conséquences

Plus d’archive construite à distance. L’application se construit sur le Mac. Les contrôles Sophos demandent un clone de Sophos à côté du projet.

## Trace

- Fichiers retirés : `.github/workflows/`, `Scripts/download-app.sh`.
